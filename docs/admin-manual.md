# Admin Operations Manual

This manual is for `admin` and `charity_manager` roles using the Filament Admin Panel.

## Accessing the Dashboard
Navigate to `/admin` and log in with your credentials. 

## Managing Campaigns
1. Click **Campaigns** in the sidebar.
2. Click **New Campaign** to create a fundraiser.
3. Set the Goal Amount, Start Date, and End Date.
4. Upload a featured image.
5. Set status to `published` when ready to accept donations.

## Generating Impact Reports
Once a campaign reaches a milestone, you should generate an impact report.
1. Click **Impact Reports** in the sidebar.
2. Link the report to a specific Campaign.
3. Provide the number of beneficiaries, funds deployed, and projects completed.
4. Input GPS coordinates for the Google Maps integration.
5. Publish the report. This will generate a public page and a downloadable PDF.

## Managing Volunteers
Volunteers register themselves via the public portal. You can view their schedules:
1. Click **Volunteer Schedules**.
2. You can verify completed hours and approve shifts here.
