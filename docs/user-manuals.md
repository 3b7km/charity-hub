# User & Operations Manuals

## Donor-Facing User Guide
Welcome to CharityHub! Here is how to navigate the platform:

- **Finding Campaigns:** Navigate to the home page or "Campaigns" directory to see active initiatives. You can view the real-time progress bar, funds raised, and deadline for each campaign.
- **Making a Donation:** Click on a campaign and select "Donate". You can choose between a one-time gift or a recurring (monthly/yearly) subscription. Payments are securely processed via Stripe/PayMob.
- **Certificates & Receipts:** Upon successful donation, a verifiable PDF certificate with a QR code will automatically be emailed to you. You can also download past certificates from your donor dashboard.
- **Volunteering:** Interested in giving your time? Navigate to the Volunteer Portal to view available shifts, sign up, and log your completed hours.

## Admin Operations Manual
This guide is for platform administrators using the Filament Admin Panel (`/admin`).

- **Campaign Management:** Go to the "Campaigns" resource to create new initiatives. Set the target goal, end date, and upload cover images.
- **Volunteer Management:** Use the "Volunteers" resource to view registered volunteers. The system automatically detects scheduling conflicts if a volunteer double-books a time slot.
- **Impact Reports:** Once a campaign concludes, go to "Impact Reports" to publish outcomes, beneficiary statistics, and verify locations via Google Maps.
- **Data Export & Communications:** Admins can trigger bulk email updates or export impact reports to PDF directly from the dashboard actions menu.
